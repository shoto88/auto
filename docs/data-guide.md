# 掲載データの集め方・入力ガイド

サイトの価値の源泉は `src/data/services.json` のデータの**網羅性と正確さ**。ここが「おすすめN選」記事との差になる。

> 2026年7月14日時点で、**実在する15サービス**(研修3・外部相談窓口5・ツール6・コンサル/士業1)を公開情報ベースで掲載済み。料金は検索で確認できた公開価格のみ記載し、未確認のものは「要問い合わせ」としている。

## データソース(優先順)

1. **各社公式サイトの料金・サービスページ** — 料金やプランが公開されているサービスから入力する。
2. **料金非公開のサービス** — 資料請求・問い合わせでヒアリングした料金レンジを載せる(非公開情報が載っていること自体が差別化になる)。掲載前に先方へ掲載可否を確認するとトラブルがない。
3. **導入事例・プレスリリース** — 得意業種や実績(strengths欄)の裏取りに使う。

## 探すべきサービスのカテゴリ

| カテゴリ | 例 | 見つけ方 |
|---|---|---|
| 研修 | カスハラ対応研修、eラーニング | 「カスハラ研修」で検索、研修ポータル(インソース等の競合他社)を横断 |
| 外部相談窓口 | ハラスメント社外窓口の受託 | 「ハラスメント 外部相談窓口 委託」で検索、EAP事業者を確認 |
| ツール | 通話録音、AI音声応対、ウェアラブル通報、防犯カメラ | 「カスハラ対策 ツール」「通話録音 クラウド」で検索 |
| コンサル・士業 | 社労士の規程整備パッケージ、危機管理コンサル | 社労士事務所のサービスページ、「カスハラ 規程 作成」で検索 |

## 掲載基準

- 事実(料金・提供内容・対応範囲)のみを記載する。**優劣の評価・口コミ・ランキングは載せない**(景表法・名誉毀損リスクを避ける)。
- 情報の取得日を管理し、半年に1回は見直す。
- 掲載拒否・修正の申し出があれば速やかに対応する。

## services.json のスキーマ

| フィールド | 型 | 説明 |
|---|---|---|
| `slug` | string | URL用の一意な英数字(例: `example-service`) |
| `name` | string | サービス名 |
| `company` | string | 提供元の会社名 |
| `category` | string | `研修` / `外部相談窓口` / `ツール` / `コンサル・士業` |
| `priceNote` | string | 料金。**公開情報で確認できた金額のみ**記載。未確認は「要問い合わせ」 |
| `target` | string | 向いている企業・利用シーン(比較表に表示) |
| `features` | string[] | 主な機能・提供内容 |
| `url` | string | 公式サイト(または該当サービスページ)のURL |
| `strengths` | string | 1文で言える強み(比較表に表示) |
| `description` | string | 詳細ページ用の紹介文(2〜3文) |
| `checkedAt` | string | 情報を確認した日付(YYYY-MM-DD)。詳細ページに表示される |

## データ運用ルール(トラブル回避のため厳守)

1. **料金は公式ページで確認できたものだけ**書く。比較記事からの又聞き数字は書かない(このリポジトリの初期データは検索結果で確認できた公開価格のみ記載)
2. 優劣の評価・ランキング・口コミは載せない(景表法・名誉毀損リスク)
3. 修正・削除依頼が来たら24時間以内に対応する
4. 半年に1回、全件の `checkedAt` を更新する(料金改定チェック)
5. 掲載社数を増やすときは、まず「カスハラ対策 ○○(カテゴリ名)」で検索し、公式サイトに料金・サービス内容の記載がある事業者を優先する
