# ジャンル再検討リサーチ(2026年7月実施)

「まだ気づかれていないが、需要が確実に来る比較・まとめサイト」を、**これから施行される法規制**と**制度変更によるデータベースの空白**を起点に調査した記録。

## 調査の考え方

「みんなが気づいてないけど当たる」領域は偶然では見つからない。再現性があるのは次の2パターン:

1. **施行日が決まっている義務化・規制** — 需要の発生時期が法律で確定しているのに、比較サイトがまだ薄い領域
2. **制度切り替えによるDBリセット** — 旧制度の事業者リストが無効になり、新制度の許可リストがゼロから公開される瞬間

## 本命: カスハラ対策ナビ(仮)

### なぜ当たるか

- **2026年10月1日**に改正労働施策総合推進法が施行され、従業員1人でも雇う**全事業主**にカスハラ対策(方針の明確化・周知、相談体制、再発防止)が義務化される。指針は2026年2月26日に正式策定済み。
- 対象は日本の全企業約360万社。パワハラ義務化(2020年大企業/2022年中小)のときと同じ構図で、施行前後に「何をすればいいのか」検索が爆発する。
- 企業が探すもの: ①基本方針のひな形 ②研修会社 ③外部相談窓口 ④録音・AI応対ツール ⑤社労士/弁護士。**①のひな形・文例がアクセスの入口**になり(検索量大・競合は記事のみ)、②〜⑤が送客マネタイズになる。
- パワハラ義務化後もハラスメント研修市場は拡大が続いた前例があり、一過性で終わらない(施行後は指導事例・罰則・業種別対応の情報需要が継続)。

### サイト構造(案)

1. **無料ひな形・テンプレ集**: 基本方針の文例(業種別)、店頭掲示ポスター、対応マニュアル、対応フローチャート → LINE登録/メールでDL(リスト資産化)
2. **対策サービスDB**: 研修会社・外部相談窓口・カスハラ対策ツール(通話録音/AI)・社労士を料金/対応範囲で構造化比較 → 送客課金
3. **業種別ガイド**: 小売・飲食・介護・自治体・コールセンター別の対応要点
4. **事例・ニュース**: 施行後の指導事例・判例のアーカイブ(継続アクセス源)

### 注意点

- 「おすすめN選」記事はKeySession・アスピック・slide lib等が既に公開 → 記事で戦わず**構造化DB+ひな形**で差別化する
- 法解釈の断定は避け、根拠は厚労省指針への参照で担保する(士業監修が入ると売却価値も上がる)
- 施行まで約3ヶ月。**今から作れば波の先頭に間に合う**タイミング

## 対抗: 監理支援機関DB(育成就労ナビ)

- 制度リセットによるDB空白は本物だが、旧監理団体の検索サイト勢が看板を替えて参入してくる可能性が高い
- ピークは2027年4月施行前後で、やや先。カスハラの次の二毛作として狙うのが合理的
- リード単価は非常に高い(監理費は月3〜5万円/人×複数年)ので、送客が決まれば少PVでも収益化できる
