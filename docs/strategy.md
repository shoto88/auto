# ショトログ 事業計画 — バイアウト(売却)までのロードマップ

## 結論

**「ショート動画運用代行会社の比較データベースサイト」を個人で立ち上げ、月次営業利益を作ったうえで、スモールM&A市場(ラッコM&A・TRANBI等)で売却する。**

ファクログ(ファクタリング比較)と同じ「ニッチ×高単価BtoBの比較メディア」モデルを、まだ比較サイトが確立していない「ショート動画運用代行」領域に適用する。

## なぜこの領域か(候補比較)

| 候補 | 個人で可能か | 実績ゼロで戦えるか | 売却しやすさ | 判定 |
|---|---|---|---|---|
| SNSプラットフォーム自体を開発 | ✕ 開発・集客とも重い | ✕ | △ 当たれば大きいが確率が低い | 見送り |
| SNS運用SaaS(予約投稿・分析) | △ 開発は可能 | ✕ Buffer等の巨人+国内競合多数 | ○ | 見送り |
| SNSアカウントを育てて売る | ○ | △ 属人性が高く再現性が低い | △ 相場が安い | 見送り |
| **ニッチ比較データベースメディア** | **○ データ整備が中心** | **○ 情報を整理する側なので実績不要** | **◎ 送客メディアはM&A市場で最も流動性が高い** | **採用** |

### 「ショート動画運用代行」を選ぶ理由

1. **需要が拡大中**: 企業のTikTok・YouTubeショート・リール参入が増え続けており、「運用代行 相場」「どこに頼むべきか」の検索意図が明確に存在する。
2. **相場が不透明**: 月5万〜100万円超まで幅があり、比較情報の価値が高い。
3. **競合が薄い**: 「動画制作会社の比較」は既存大手がいるが、**ショート動画特化の構造化データベース**(料金レンジ・最低契約期間・対応範囲を統一フォーマットで比較)はまだ確立していない。
4. **マネタイズ先が明確**: 代行会社側は顧客獲得コストが高く、掲載費・送客費を払う動機が強い。BtoBリードは1件あたりの単価が高い(相場1〜3万円/件)。
5. **AI検索時代への耐性**: 記事の寄せ集めではなく「構造化データベース」なので、AI要約に代替されにくく、指名利用が育つ。

## マネタイズ(3段階)

1. **アフィリエイト(初期)**: 動画編集ツール・スクール・クラウドソーシングのアフィリエイトで最初の収益を作る。
2. **送客課金(中期・本命)**: 問い合わせフォーム経由の紹介1件あたり1〜3万円を代行会社に課金。まず無料掲載で網羅性を作り、問い合わせが発生し始めた段階で有料化を打診する。
3. **掲載プラン(後期)**: 上位表示・取材記事・「認定バッジ」等の月額掲載プラン(月1〜5万円)。

## 集客(SNSを集客エンジンにする)

- **SEO**: 「ショート動画 運用代行 料金」「TikTok 運用代行 相場」等の比較・相場キーワード。データベース構造がそのままロングテールページ群になる。
- **TikTok / YouTubeショート本体で発信**: 「運用代行の相場」「見積もりの見方」「契約前チェックリスト」等の解説ショート動画を投稿し、サイトへ誘導。**この領域のメディアが自らショート動画で集客する構図は説得力が高く、売却時のアピールにもなる。**
- **LINE公式アカウント**: 「相場早見表PDF」等を特典に友だち登録を促し、見込み客リストを資産化。LINEリストは譲渡可能な資産として売却価格に上乗せできる。

## KPIとロードマップ

| 期間 | やること | 目標 |
|---|---|---|
| 0〜3ヶ月 | 実データ整備(30〜50社)、相場ガイド拡充、独自ドメイン取得、問い合わせフォーム設置 | 掲載50社 / 検索インデックス確立 |
| 3〜6ヶ月 | SEO記事を月2〜4本、解説ショート動画の投稿開始、LINE公式開設 | 月間5,000PV / 初問い合わせ発生 |
| 6〜12ヶ月 | 送客課金の開始(問い合わせ実績を持って代行会社に営業)、掲載プラン設計 | 月間2〜3万PV / 月次利益5〜15万円 |
| 12〜24ヶ月 | 収益の安定化・運用の仕組み化(属人性の排除)、売却準備 | 月次利益20〜30万円で安定 |

## バイアウト(出口)設計

- **売却先市場**: ラッコM&A、TRANBI、M&A総合研究所(小規模案件)等。送客型・アフィリエイト型メディアは最も取引件数が多いカテゴリ。
- **価格相場**: 月次営業利益の**24〜36ヶ月分**が目安。月次利益20万円で安定すれば **480万〜720万円** のレンジ。
- **売却価格を上げる設計(最初から仕込む)**:
  - **属人性を排除**: 更新手順・掲載基準・営業テンプレをすべてドキュメント化(このリポジトリの `docs/` に蓄積する)。
  - **資産を一括譲渡可能に**: ドメイン・サイト・SNSアカウント・LINE公式・広告主契約をセットで譲渡できる形にしておく。
  - **収益の分散**: アフィリエイト単一依存を避け、送客課金+掲載プランの複線化で「Google依存リスク」の値引きを防ぐ。
  - **記録を残す**: PV・問い合わせ数・収益の月次推移をスプレッドシートで記録(デューデリジェンス資料になる)。

## リスクと対策

| リスク | 対策 |
|---|---|
| Googleアップデート・AI検索でSEO流入減 | 構造化DB+指名検索+LINEリスト+SNS流入で分散 |
| 参入障壁が低く模倣される | データの鮮度・網羅性・ヒアリング情報(非公開料金)で先行者優位を作る |
| 掲載企業とのトラブル | 掲載基準を明文化し、事実ベース(料金・条件)の記載に徹する。口コミ・評価は法務リスクが高いので初期は載せない |
| 市場自体の縮小 | ショート動画市場は拡大局面。仮に鈍化しても「動画マーケ全般」へ横展開可能なドメイン設計にする |
