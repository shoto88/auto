# カスハラ対策ナビ 事業計画 — バイアウト(売却)までのロードマップ

## 結論

**「カスハラ対策の総合情報サイト(ひな形×サービス比較DB)」を2026年10月1日の義務化施行前に立ち上げ、施行前後の検索需要の波でアクセスとリードを獲得し、月次営業利益を作ったうえでスモールM&A市場(ラッコM&A・TRANBI等)で売却する。**

ジャンル選定の調査過程と他候補の検証結果は [`genre-research.md`](genre-research.md) を参照。

## なぜ勝てるか

1. **需要の発生が法律で確定している**: 2026年10月1日施行の改正労働施策総合推進法により、中小を含む全事業主(約360万社)にカスハラ対策が義務化される。施行前後に「何をすればいいのか」検索が確実に爆発する。
2. **アクセスの入口が「ひな形」**: 企業担当者が最初に探すのは「基本方針 文例」「店頭掲示 テンプレート」。競合は解説記事ばかりで、そのまま使えるひな形+業種別カスタマイズをセットで出しているサイトは薄い。
3. **マネタイズ先が明確**: 研修会社・外部相談窓口・録音/通報ツール・社労士/コンサルはいずれも顧客獲得に費用を払うBtoB事業者。送客リードの単価が高い(1〜3万円/件の世界)。
4. **一過性で終わらない**: パワハラ義務化(2020/2022年)後もハラスメント研修・外部窓口市場は拡大が続いた。施行後は指導事例・業種別対応・体制見直しの情報需要が継続する。
5. **競合は記事、こちらはDB+ひな形**: KeySession・アスピック等の「おすすめN選」記事とは形式で差別化する(構造化比較+実務ドキュメント)。

## マネタイズ(3段階)

1. **リスト獲得(初期)**: ひな形のWord/PDF版を「メール or LINE登録でダウンロード」にして見込み客リストを資産化。リスト自体が売却時の上乗せ資産になる。
2. **送客課金(中期・本命)**: 比較ページ・詳細ページから外部相談窓口/研修会社への問い合わせ送客。1件1〜3万円、または成約課金。
3. **掲載プラン(後期)**: 上位掲載・取材記事・「掲載certified」等の月額プラン(月1〜5万円)。士業(社労士)向けの地域別掲載枠も有望。

## 集客

- **SEO**: 「カスハラ 基本方針 文例」「カスハラ対策 義務化 いつから」「カスハラ 外部相談窓口 比較」等。ひな形ページと義務化ガイドが柱。
- **SNS(ショート動画)**: 「10月から全企業に義務化されます、罰則は?」系の解説ショートはバズりやすいテーマ。TikTok/YouTubeショート→サイト誘導→LINE登録の動線。
- **LINE公式**: ひな形DL特典で友だち化。施行直前(8〜9月)に「対応チェックリスト」配信で再訪を作る。
- **プレスリリース**: 施行タイミングは記者も題材を探すので、独自調査(「中小企業の対応率アンケート」等)でメディア掲載を狙える。

## バイアウト(出口)設計

- **売却先市場**: ラッコM&A、TRANBI等。情報サイト+リスト+送客契約のセットは最も流動性が高いカテゴリ。
- **価格相場**: 月次営業利益の24〜36ヶ月分が目安。月次利益20万円で安定すれば480万〜720万円のレンジ。
- **売却価値を上げる設計(最初から仕込む)**:
  - 更新手順・掲載基準・営業テンプレを `docs/` にドキュメント化し属人性を排除
  - ドメイン・サイト・LINE公式・SNSアカウント・広告主契約を一括譲渡できる形に
  - 収益をアフィリエイト単一に依存させず、送客+掲載プランで複線化
  - PV・リスト数・リード数・収益の月次推移を記録(デューデリジェンス資料)
  - 士業監修を入れる(信頼性が上がり、譲渡後も監修契約ごと引き継げる)

## リスクと対策

| リスク | 対策 |
|---|---|
| 施行後に検索需要が減衰する | パワハラ義務化の前例では市場は施行後も拡大。指導事例・判例アーカイブで恒常需要を取る。第2サイト(育成就労)への横展開も準備 |
| 大手BtoB媒体が本気を出す | 記事では勝負せず「ひな形×構造化DB×業種別」の実務特化で差別化。ニッチすぎて大手はDB整備までやらない |
| 法解釈の誤りによる信頼失墜 | 断定を避け厚労省指針への参照で担保。早期に社労士監修を入れる |
| 掲載事業者とのトラブル | 事実ベース掲載・評価/ランキング非掲載・修正依頼への迅速対応(掲載基準を明文化済み) |

## 集客の追加武器: 東京都奨励金(40万円)

東京都は都内中小企業のカスハラ対策に**奨励金40万円**を支給している(事前エントリー制・受付回ごと募集)。この制度はサイトにとって三重に美味しい:

1. **検索需要**: 「カスハラ 奨励金」「カスハラ 補助金 東京都」は商業意図が強く競合が薄い
2. **送客導線**: 支給要件の「録音・録画/AI導入/外部人材活用」が、そのまま掲載サービス(ツール・研修・窓口)への導線になる
3. **更新ネタ**: 受付回ごとに「第N回受付開始」の更新記事が書け、鮮度を維持できる

→ `/subsidy/` ページとして実装済み。他自治体の同種制度が出てきたら横展開する。
